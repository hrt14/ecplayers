# Amazon広告 除外発見機

Amazon Ads の検索語句レポート CSV/TSV をブラウザ内で解析し、十分なクリック実績があるのに成果が目標を外れている検索語句を除外候補として一覧化します。

- 初期判定は 20 クリック以上
- 目標 ACOS / 最低クリック数 / 最低広告費を変更可能
- 除外推奨・要判断・継続・データ不足で分類
- 人がチェックを外して最終判断
- 選択結果を CSV 出力
- ASIN 形式はキーワードと分けて商品除外候補として出力
- 選択結果入りの改善提案スライド生成プロンプトを作成

判定ロジックの根拠として、Amazon Ads 公式ガイドの検索語句レポート・ネガティブターゲティング・Bulksheets の説明を参照しています。
